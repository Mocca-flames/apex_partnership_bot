================================================================================
  NOTES FOR IMAGE GENERATION
================================================================================

1. CONSISTENCY: Use the same visual style across all images (flat vector, clean
   lines, minimal gradients). This ensures the PDF looks cohesive.

2. BRAND COLORS: Always reference the exact hex codes provided. For DALL-E, mention
   the color names and hex values. For Midjourney, use --style raw and include
   hex values in the prompt.

3. TEXT OVERLAYS: DALL-E and Midjourney may not render text accurately. All prompts
   request NO TEXT in the generated image. Add text overlays manually in a design
   tool (Figma, Canva, Adobe Illustrator) after generation.

4. FILE FORMAT: Export all images as PNG with transparent or white backgrounds.
   Use 2x resolution for crisp rendering in PDF.

5. PDF PLACEMENT: Map images to the TUTORIAL.md sections:
   - Cover image: PDF title page / header
   - Image 2 (Tutorial PDF): Step 1 section
   - Image 3 (Practice Test): Step 2 section
   - Image 4 (Submit Lead): Step 3 section
   - Image 5 (Check Status): Step 4 section
   - Image 6 (Lifecycle): Lead Lifecycle section
   - Image 7 (Commission): How Much You Earn section

6. MIDJOURNEY: Always append --no text, words, letters, typography to avoid
   garbled text generation. Add text manually in post-production.

7. DALL-E: Request "no text in the image" in the prompt and overlay text using
   a separate tool for maximum control over typography and brand compliance.
